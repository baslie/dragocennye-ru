# Catalog Browse

## Overview

Главный экран магазина «Драгоценные» — живой листинг коллекционных камней с визуальной навигацией по
видам и быстрыми фильтрами, без сайдбаров и лишнего скролла. Страница одновременно SEO-посадочная для
запросов «[цвет] [вид] купить» и главный навигатор по ассортименту.

## User Flows

- Заход на `/catalog` → сетка всех камней (таб «Все» активен), табы видов сверху, тонкая строка фильтров и сортировки под ними.
- Клик по табу вида → URL `/catalog/[variety]`, появляется H1 + SEO-описание, сетка перерисовывается live.
- Открытие чипа «Цвет» и выбор значения → URL `/catalog/[variety]/[color]`, мгновенная фильтрация.
- Чипы Огранка / Вес / Цена / Происхождение / Обработка / Сертификат + дропдаун сортировки — live, счётчик найденных обновляется.
- Пагинатор (12 камней на страницу) — плавный скролл к началу сетки.
- Клик по карточке → Stone Detail.
- Пустая выборка → empty state «Камней по вашему запросу не нашлось» + «Сбросить фильтры».

## Design Decisions

- **Табы видов картинками** вместо текстового меню — визуальный вход в подкатегории. Активный — steel `#576A8F`, hover — coral `#FF7444`.
- **Тонкая строка фильтров** вместо тяжёлого сайдбара — чипы-дропдауны экономят вертикаль; на mobile сворачиваются в bottom-sheet.
- **Карточки — визуальный минимум** (фото, название, цена). Никаких бейджей статуса/сертификата — это уровень Stone Detail.
- **Live-фильтры** без кнопки «Применить»: любое изменение применяется сразу, URL и счётчик обновляются в реальном времени.
- Широкий layout `max-w-[1680px]`, сетка до 5 колонок на xl. Только светлая тема.

## Data Shapes

**Entities:** `StoneVariety`, `Cut`, `Origin`, `Treatment`, `Color`, `Certificate`, `Stone`, `CatalogFilters` (+ типы `ColorSlug`, `CutSlug`, `TreatmentSlug`, `SortOption`).

**From global entities:** Stone, StoneVariety, Cut, Origin, Treatment, Certificate — здесь в облегчённой форме листинга.

## Components Provided

- `CatalogBrowse` — корневой компонент секции.
- `VarietyTabs` — лента табов видов камней.
- `FilterBar` — строка чипов-фильтров + сортировка + счётчик.
- `SeoBlock` — H1 вида и описание (при выбранном виде).
- `StoneCard` — карточка камня.
- `Pagination` — постраничная навигация.
- `EmptyState` — состояние пустой выборки.

## Callback Props

| Callback | Triggered When |
|----------|---------------|
| `onSelectVariety(varietyId \| null)` | Клик по табу вида или «Все» |
| `onFilterChange(filters)` | Изменение любого чипа фильтра |
| `onSortChange(sort)` | Смена сортировки |
| `onPageChange(page)` | Смена страницы |
| `onStoneClick(stoneId)` | Клик по карточке камня |
| `onResetFilters()` | «Сбросить фильтры» в empty state |
