# Liquid Glass — прототипы

Перенесено из удалённого репозитория `dragocennye-lg`: эксперименты с эффектом Liquid Glass для будущего дизайна магазина.

- `demo.html` — демо-страница с эффектом Liquid Glass (бывший `test.html`).
- `photos.html` — галерея фото камней в стиле Liquid Glass (бывший `test-photos.html`). Фото берутся из `../about-project/photos/`.

Открываются напрямую в браузере, без сборки.
