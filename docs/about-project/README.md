# dragocennye-ru

Каталог драгоценных камней — тексты и фотографии товаров, подготовленные как исходный материал для будущего интернет-магазина.

## Что это

Репозиторий — это «сырьё» для нового проекта интернет-магазина драгоценных камней. Здесь лежат:

- структурированный каталог товаров в Markdown;
- все фотографии товаров, разложенные по категориям и артикулам;
- постановка задачи по переезду с Tilda на самописную платформу.

Сам магазин (фронтенд, бекенд, админка) будет разрабатываться отдельно — этот репозиторий держит контент, от которого он будет отталкиваться.

## Содержание

- **`catalog.md`** — единый каталог: 224 позиции в 23 категориях, с артикулами, названиями, ценами, описаниями и ссылками на папки с фото.
- **`photos/`** — 554 фотографии товаров, структура `photos/<Категория>/<SKU-slug>/NN.ext`.
- **`docs/prompts.md`** — постановка задачи: контекст переезда с Tilda, референсы крупных поставщиков, требования к структуре нового магазина.

## Категории

Сапфир, Шпинель, Турмалин, Гранат, Кварц, Топаз, Циркон, Берилл, Опал, Хризолит, Танзанит, Кунцит, Апатит, Хризоберилл, Сфен, Грандидьерит, Лунный камень, Хризопраз, Нефрит, Хромдиопсид, Андалузит, Иолит, Лазурит.

## Этапы работы

1. **Сделано** — экспорт товаров из Tilda, загрузка фотографий, сборка единого каталога.
2. **Сделано** — фиксация постановки задачи по переезду с Tilda (`docs/prompts.md`).
3. **В работе** — разработка нового интернет-магазина драгоценных камней на основе этого каталога.

## Статус

Приватный репозиторий, используется как контент-основа для разработки магазина.
